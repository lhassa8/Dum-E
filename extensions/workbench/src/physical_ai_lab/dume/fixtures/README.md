The bundled recognition-warmup.wav contains only synthetic Mac `say` speech:
“Bring me the screwdriver, please.” It was generated for the saved-speech
regression and converted by ffmpeg to 16kHz mono PCM. It contains no microphone
recording. Startup transcribes it locally and discards the result; it does not
speak, access the microphone, submit a task or move the robot.
